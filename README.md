# Codex 微信桥接

通过微信 ClawBot 接收 Windows Codex 桌面的审批、问题和任务结果，并在手机上回复、继续已有聊天。当前版本：`0.2.0`。

## 当前支持的功能

| 功能 | 使用效果 |
| --- | --- |
| 微信审批 | 同步命令执行、文件修改、网络或文件系统权限请求，在微信同意或拒绝。 |
| 简短编号与免编号审批 | 请求使用纯数字短编号，提供可长按复制的独立回复；只有一条已通知且可用的待审批时，直接回复“同意”或“拒绝”。 |
| 回答问题 | 支持选项和自由文字回答，答案回填原桌面聊天；覆盖原生阻塞式提问和桌面异步问题卡片。 |
| MCP 确认与表单 | 支持 URL 确认和简单 JSON 表单。 |
| 完成、失败与中断提醒 | 自动发送聊天名称、最终回复摘要及错误原因（如有）；首次订阅不补发旧的完成记录，未送达结果支持重试。 |
| 状态与待处理清单 | 查看聊天编号、运行状态，以及需要审批或回答的项目和回复方式。 |
| 继续已有聊天 | 指定聊天发送文字；执行中追加消息，空闲时开始下一回合，继承桌面的模型、目录与审批设置。 |
| 桌面与微信并行 | 桌面弹窗即时显示，两端都能处理；微信提交前复查状态，已结束的请求不再提交。 |

命令与文件审批只批准本次操作；权限请求仅授权本回合。聊天和请求各自编号，避免多聊天之间误操作。

## 微信常用指令

| 发送内容 | 作用 |
| --- | --- |
| `连接` | 建立或刷新微信消息上下文。 |
| `状态` | 查看聊天清单与运行状态；也支持 `聊天`、`任务`。 |
| `待处理` | 查看审批和问题清单；也支持 `待办`。 |
| `同意` / `拒绝` | 处理唯一一条已通知且可用的待审批。 |
| `同意101` / `拒绝101` | 按编号处理审批，多条审批时使用。 |
| `回答102 2` | 选择问题中的第 2 个选项。 |
| `回答102 你的答案` | 用自由文字回答问题；编号与答案间留空格。 |
| `切换1` | 选择“聊天1”，之后直接发送文字即可续聊。 |
| `继续1 把测试也跑一下` | 向“聊天1”发送指令，并将它设为当前聊天。 |
| `帮助` | 查看简要用法。 |

多个聊天尚未选择时，普通文字不会猜测发送目标。选中的聊天断开时，也不会自动切换到其他聊天。有待处理审批或问题时，先完成对应回复再续聊。

## 适用范围与验证

- 适用于 Windows Codex 桌面当前持有、已加载的本地聊天；直接扫码连接 ClawBot，无需安装完整 OpenClaw。
- 复杂 MCP 表单与身份验证仍需在桌面处理；普通聊天文字中的疑问句不会自动识别为问题卡片。
- 暂未支持微信创建新聊天、语音和图片输入、开机自启及免打扰设置。
- 已适配的 Windows 包版本为 `26.1013.4894.0`，包内应用版本为 `26.1013.40934`。使用内部桌面 IPC，桌面升级后可能需要适配。
- 49 项自动测试通过；微信收发、审批与问答、状态清单和执行中续聊已做本机实测。空闲聊天开启下一回合通过协议模拟验证。
